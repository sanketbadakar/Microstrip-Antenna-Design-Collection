# VNA Measurements

## Overview

This directory contains the **Vector Network Analyzer (VNA)** measurement results of the proposed **T-shaped microstrip antenna**.

The measurements were performed to validate the antenna's impedance matching characteristics and compare the measured performance with the simulated results obtained using **ANSYS HFSS**.

## Included Results

| Measurement | Description |
|------------|-------------|
| S11 | Measured return loss characteristics |
| VSWR | Measured Voltage Standing Wave Ratio |
| Smith Chart | Measured impedance characteristics |

These measurement results provide experimental validation of the antenna's performance and support the simulation-based analysis presented in this repository.
