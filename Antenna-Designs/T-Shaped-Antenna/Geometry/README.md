# Geometry

## Overview

This directory contains the geometric representations of the proposed microstrip antenna developed using **ANSYS HFSS & CST Microwave Studio**.

The geometry files provide a clear visualization of the antenna structure from different perspectives, including the radiating patch, substrate and ground plane.

## Included Figures

| Figure | Description |
|---------|-------------|
| Patch-Substrate-Top-View | Top view of the radiating patch and substrate |
| Ground-Plane-Bottom-View | Bottom view of the ground plane |

These figures provide the complete geometric representation of the antenna design used for electromagnetic simulation and performance evaluation.
