# VNA Measurements

## Overview

This directory contains the **Vector Network Analyzer (VNA)** measurement results of the proposed **U-shaped microstrip antenna**.

The measurements were carried out to evaluate the antenna's impedance matching performance and verify the simulated results obtained using **ANSYS HFSS**.

## Included Results

| Measurement | Description |
|------------|-------------|
| S11 | Measured return loss characteristics |
| VSWR | Measured Voltage Standing Wave Ratio |
| Smith Chart | Measured impedance characteristics |

These measurement results provide experimental validation of the antenna's performance and enable comparison between simulated and measured characteristics.
