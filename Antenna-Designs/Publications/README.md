
# Published Paper

## Overview

This directory contains the published IEEE research paper associated with the antenna designs presented in this repository.

The publication presents the design methodology, simulation process, performance evaluation, and comparative analysis of the proposed **T-shaped, U-shaped, and H-shaped microstrip antennas** developed using **ANSYS HFSS**. It serves as the official research reference for the work documented throughout this repository.

## Publication Details

- **DOI:** 10.1109/ICCTWC68241.2026.11583333
- **IEEE Xplore:** https://ieeexplore.ieee.org/document/11583333


The published paper provides comprehensive technical details that complement the antenna designs, simulation results, VNA measurements, and supporting documentation available throughout this repository.
