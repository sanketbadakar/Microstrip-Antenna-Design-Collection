# VNA Measurements

## Overview

This directory contains the **Vector Network Analyzer (VNA)** measurement results of the proposed **H-shaped microstrip antenna**.

The measurements were conducted to assess the antenna's impedance characteristics and validate the simulation results obtained using **ANSYS HFSS**.

## Included Results

| Measurement | Description |
|------------|-------------|
| S11 | Measured return loss characteristics |
| VSWR | Measured Voltage Standing Wave Ratio |
| Smith Chart | Measured impedance characteristics |

These measurement results provide experimental validation of the antenna's performance and demonstrate the agreement between practical measurements and simulation results.
