# H-Shaped Microstrip Antenna

## Overview

This folder contains the design, simulation results, and technical documentation for the **H-Shaped Microstrip Antenna** developed using **ANSYS HFSS**.

The antenna was designed and simulated to analyze its electromagnetic performance through key antenna parameters, including return loss, impedance matching, gain, VSWR, Smith chart, and far-field radiation characteristics.
