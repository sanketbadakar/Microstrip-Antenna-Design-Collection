# H-Shaped Microstrip Antenna

## Overview

The H-shaped microstrip antenna is the third antenna configuration investigated in this repository. The antenna was designed and simulated using **ANSYS HFSS** to examine the impact of an H-shaped radiating structure on impedance matching, radiation characteristics, and overall electromagnetic performance.

The antenna performance was analysed through full-wave electromagnetic simulation using return loss (S11), VSWR, Smith chart, gain, and far-field radiation pattern. The simulation results provide a comprehensive basis for comparison with the T-shaped and U-shaped antenna designs.

---

## Design Objectives

The objectives of this antenna design include:

- Investigate the electromagnetic performance of an H-shaped microstrip antenna.
- Analyse impedance matching characteristics.
- Evaluate gain and radiation performance.
- Study the antenna's resonant behaviour through simulation.
- Compare its performance with T-shaped and U-shaped antenna configurations.
