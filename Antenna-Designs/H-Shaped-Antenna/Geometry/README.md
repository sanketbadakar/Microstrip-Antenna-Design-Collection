# Geometry

## Overview

This directory contains the geometric representations of the proposed **H-shaped microstrip antenna** developed using **ANSYS HFSS & CST Microwave Studio**.

The geometry files provide a clear visualization of the antenna structure from different perspectives, including the radiating patch, substrate, and ground plane.

## Included Figures

| Figure | Description |
|---------|-------------|
| Patch-Substrate-Top-View | Top view of the H-shaped radiating patch and substrate |
| Ground-Plane-Bottom-View | Bottom view of the ground plane |

These figures illustrate the complete geometric configuration of the H-shaped microstrip antenna used for electromagnetic simulation, performance evaluation, and comparative analysis.
