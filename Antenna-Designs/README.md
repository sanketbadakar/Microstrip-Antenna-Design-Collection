# HFSS Antenna Design Portfolio

### Design and Simulation of T-Shaped, U-Shaped, and H-Shaped Microstrip Antennas Using ANSYS HFSS

---

## Project Overview

This repository presents the design simulation of three different microstrip antenna configurations developed using **ANSYS HFSS**. The project demonstrates the complete design workflow and comparative analysis of **T-shaped**, **U-shaped**, and **H-shaped** microstrip antennas.

Each antenna design is documented with its corresponding geometry, return loss (S11), radiation characteristics, gain analysis, VSWR, and Smith chart. The repository has been structured to serve as a technical reference for students, researchers, and RF engineers interested in antenna design and wireless communication systems.

---

## Objectives

The primary objectives of this project are:

- Design and Simulate three different microstrip antenna geometries using ANSYS HFSS.
- Compare the radiation characteristics and impedance behaviour of different antenna geometries.
- Present the simulation results in a structured and easy-to-understand format.
- Provide a technical learning resource for antenna design and wireless communication studies.
